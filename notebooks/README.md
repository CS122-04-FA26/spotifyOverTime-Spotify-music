# Notebooks (`notebooks/`)

- `EDA_for_Spotify_Over_Time.ipynb` — Exploratory Data Analysis of audio feature distributions, chronological era trends, genres, and mood clusters across the 150K cleaned Spotify dataset.
- `Model_Training_Spotify_Over_Time.ipynb` — End-to-end feature engineering, model training, ordinal framing, MLP benchmarking, confusion matrices, and production model selection across **Logistic Regression**, **Random Forest**, **Gradient Boosted Decision Trees**, **Ordinal GBDT**, and **MLP Neural Network** using `data/train_data.csv` and `data/test_data.csv`.
